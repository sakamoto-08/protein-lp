# プロテイン パーソナル診断機能付きLP（PortFolio）

ユーザーの目的や悩みに合わせて最適なプロテインを提案する、インタラクティブな1ページ完結型Webサイトです。

## 💡 プロジェクト概要
* **ターゲット**: 自分に合うプロテインが分からず購入を迷っているライトユーザー
* **解決する課題**: 選択肢が多すぎて選べない悩みに対し、簡単な3〜4問の質問で最適な解を提示
* **主な機能**: 
  * JavaScriptによる診断ロジック＆状態管理
  * リアルタイム価格・シミュレーター機能
  * 入力バリデーション付きお申し込みフォーム

## 🛠️ 使用技術（技術スタック）
* **フロントエンド**: HTML5, CSS3 (BEM手法), JavaScript (Vanilla JS)
* **バージョン管理**: Git, GitHub
* **デプロイ環境**: GitHub Pages

## 📱 対応デバイス
* レスポンシブ対応（スマートフォン / タブレット / PC）
